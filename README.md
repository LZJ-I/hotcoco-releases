# HotCoco 资源分发

此公开仓库只用于分发已确认的客户端资源版本，应用源码保存在独立私有仓库。

维护者在 HotCoco 网站后台导入本地导出包、核对资源并提出发布；另一位有确认权限的员工同意后，后台完成校验并发布。

- 第三方 Mod、材质包和光影使用其原有下载来源，本仓库仅记录版本和校验信息。
- 自有资源通过 `hotcoco.resources.zip` 分发，ZIP 内保留维护者的原目录和文件名。
- 每个版本提供签名清单、公钥和资源 SHA256；启动器安装名遵循清单中的 `path`。
- 测试、稳定渠道分别维护；玩家自行增加或修改的资源遵循保留策略。

公开渠道接口：[HotCoco 客户端版本](https://hotcoco.cn/api/hmcl/releases)。

首次授权完成并经过真实员工确认后才会产生正式资源版本；验收使用的临时草稿已移除。
